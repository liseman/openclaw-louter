Public and auditable—not anonymous

Every accepted report comes from a public GitHub issue and is linked to its author. Louter sends counters, a random installation ID, a reporting date and its version. It does not send prompts, responses, session identifiers, model names, local paths or provider credentials.

Retries replace the latest cumulative snapshot rather than adding it again. Closing or withdrawing a report excludes it from the next rebuild; prior GitHub history and copies may remain. Self-reported totals can be inaccurate or manipulated.
